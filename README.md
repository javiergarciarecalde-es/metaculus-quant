# metaculus-quant
Bot para los torneos de pronósticos de Metaculus (FutureEval + MiniBench). Proyecto hermano de
quiniela-quant y betfair-quant. Sin dinero en juego.

- Estado y pasos pendientes: [`docs/ESTADO.md`](docs/ESTADO.md)
- Instrucciones permanentes: [`CLAUDE.md`](CLAUDE.md)
- Basado en la plantilla oficial [metac-bot-template](https://github.com/Metaculus/metac-bot-template)
  y en ideas (no código) de [nostreambot](https://github.com/No-Stream/nostreambot-metaculus-bot) (MIT).

Probar en local: `pip install -r requirements-dev.txt` y `python -m pytest -q`.
